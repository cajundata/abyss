# Phase 1 — UI Design Contract

> Visual and interaction contract for the v0.1 Dogfoodable Vault. Generated by gsd-ui-researcher, verified by gsd-ui-checker. Mantine v8.3.18 is the component library (locked by `CLAUDE.md` §1a + `01-CONTEXT.md` D-08); shadcn/Radix does not apply.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn not applicable — Mantine is the locked component library) |
| Preset | not applicable |
| Component library | Mantine v8.3.18 (`@mantine/core`, `@mantine/hooks`, `@mantine/form`, `@mantine/notifications`, `@mantine/modals`) |
| Icon library | `@tabler/icons-react` v3.x (Mantine-idiomatic; tree-shakable; matches Mantine docs examples) |
| Font | System sans-serif stack via Mantine default (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`). No custom webfont — keeps Wails bundle small and matches OS look on macOS + Windows |

**Theme bootstrap (locked):**
- Wrap `<App />` in `<MantineProvider theme={appTheme} defaultColorScheme="auto">` (CONTEXT D-15).
- Import order in `frontend/src/main.tsx`: `@mantine/core/styles.css` → `@mantine/notifications/styles.css` → app styles. Required by Mantine v8 layered styles.
- `appTheme` overrides Mantine defaults to enforce the 8-point spacing scale and 4-step typography ramp specified below.

**Cross-platform note:** macOS WebKit and Windows WebView2 render the system font stack natively; no font fallback flicker. Focus rings use Mantine's `focusRing="auto"` (visible on keyboard, hidden on mouse) — both engines respect `:focus-visible`.

## Spacing Scale

Declared values (strict 8-point scale; overrides Mantine's default 10/12/16/20/32 via `theme.spacing`):

| Token | Value | Mantine override key | Usage |
|-------|-------|---------------------|-------|
| xs | 4px | `theme.spacing.xs = '4px'` | Icon-to-text gap, badge inner padding, masked-secret dot spacing |
| sm | 8px | `theme.spacing.sm = '8px'` | Compact stack gaps, tag chip padding, button-group gaps |
| md | 16px | `theme.spacing.md = '16px'` | Default form-field vertical gap, card inner padding, inline group gaps |
| lg | 24px | `theme.spacing.lg = '24px'` | Form section spacing, card-to-card gaps |
| xl | 32px | `theme.spacing.xl = '32px'` | Page padding (top/bottom), screen header → content gap |
| 2xl | 48px | `theme.other.spacing2xl = '48px'` | Welcome screen vertical rhythm between hero + button stack |
| 3xl | 64px | `theme.other.spacing3xl = '64px'` | Welcome screen top padding on large windows |

**Touch target minimum:** 36px height for primary buttons, 32px for secondary/icon buttons (Mantine `size="md"` and `size="sm"` defaults already align). Lock toggle and "Clear now" buttons must hit 36px to read as primary affordances.

**Exceptions:**
- Clipboard countdown progress bar height: **6px** (PRD §9.7 implies a slim, calm bar; not a spacing token, a component dimension).
- Lock-state pill indicator height: **20px** (Mantine `<Badge size="sm">` default; used in vault-status header chip).

## Typography

Locked 4-step ramp; overrides Mantine's default 5-step ramp via `theme.fontSizes` and `theme.headings`. System font stack throughout.

| Role | Size | Weight | Line Height | Mantine usage |
|------|------|--------|-------------|----------------|
| Label | 14px | 500 (medium) | 1.4 | `<Text size="sm" fw={500}>` — form labels, field hints, masked-secret captions, badge text |
| Body | 16px | 400 (regular) | 1.5 | `<Text>` default — record list rows, detail field values, modal body, error messages |
| Heading | 22px | 600 (semibold) | 1.3 | `<Title order={2}>` — screen headers (e.g., "Vault Home", "Create Vault"), record-detail title, modal titles |
| Display | 28px | 700 (bold) | 1.2 | `<Title order={1}>` — Welcome screen wordmark / hero only. Used **once per screen** at most |

**Locked weights: 400 + 600 + 700.** No 300/500-only families needed; system stack supplies all three.

**Monospace exception:** Generated-secret display fields (password generator output, masked-secret reveal, copy-target value) use `font-family: ui-monospace, SF Mono, Consolas, monospace` at 16px / 400 / 1.5. This is the only deviation from the system sans stack and is mandatory — secrets MUST render in a fixed-width font so the user can visually verify character ambiguity (`O` vs `0`, `l` vs `1`).

**Numerals:** Clipboard countdown remaining-seconds digit and master-password length counter (`{n} / 12 minimum`) use `font-variant-numeric: tabular-nums` so the number doesn't shift width as it counts down.

## Color

Phase 1 uses Mantine's semantic surface tokens (auto light/dark via `defaultColorScheme="auto"`). Hex values below are the **light scheme**; dark scheme values come from Mantine's built-in dark palette and must remain at the same role positions.

| Role | Light hex | Dark hex | Usage (60/30/10 split) |
|------|-----------|----------|-------------------------|
| Dominant (60%) | `#FFFFFF` (`--mantine-color-body`) | `#1A1B1E` (`--mantine-color-body`) | Page background, modal background, input field surface |
| Secondary (30%) | `#F8F9FA` (`gray.0`) | `#25262B` (`dark.6`) | Card surfaces (record rows, detail panels), header bar, sidebar/nav background, settings menu surface |
| Accent (10%) | `#228BE6` (`blue.6`, `--mantine-primary-color-filled`) | `#339AF0` (`blue.5` in dark) | **See accent reservation list below** |
| Destructive | `#FA5252` (`red.6`) | `#FF6B6B` (`red.5`) | Delete-record button, "Disabled with warning" auto-lock setting (Phase 2), AppErrorCode display banner |
| Lock-state ON (locked, secure) | `#40C057` (`green.6`) | `#51CF66` (`green.5`) | Vault status header pill when locked: shield icon + "Locked" label. Read as "vault is at rest, encrypted" |
| Lock-state OFF (unlocked, exposed) | `#FAB005` (`yellow.6`) | `#FCC419` (`yellow.5`) | Vault status header pill when unlocked: open-shield icon + "Unlocked" label. Read as "secrets currently in memory — caution" |

**Accent reserved for (explicit list — never "all interactive elements"):**
1. Primary CTA on each screen (`<Button variant="filled" color="blue">`): "Create Vault", "Unlock", "Save", "Generate", "Copy"
2. Active route in nav / selected record row in list
3. Focus ring outline on all focusable elements (Mantine `focusRing="auto"` uses primary color)
4. Clipboard countdown progress-bar fill while seconds > 5
5. Linked-text affordances inside body copy (e.g., "View security limitations" link on Welcome)

**Accent NOT used for:**
- Secondary buttons (`variant="default"` neutral)
- Card borders (use Mantine `var(--mantine-color-default-border)` neutral gray)
- Tag chips (Mantine `variant="light"` `color="gray"` for non-semantic tags; user-applied tags rendered in light gray, color-by-tag-name deferred to v1.x)
- Hover states on non-CTA elements (use `var(--mantine-color-default-hover)`)

**Destructive reserved for:**
- Delete-record confirmation button label ("Delete")
- Wrong-password / unlock failure inline error banner
- AppErrorCode display when `code` ∈ `{CORRUPT_VAULT, UNSUPPORTED_VAULT, MIGRATION_FAILED}`

**Lock-state contrast rule (PRD §9.5 / UI-13 — "locked vs unlocked must be visually unambiguous"):**
The lock pill is the **single canonical** lock-state surface. It MUST appear in the top-right of every screen header EXCEPT Welcome / Create Vault / Unlock (where the vault is by definition not yet open). Pill includes both color AND icon AND text label — no color-only signal (accessibility). Locked = green shield + "Locked"; Unlocked = yellow open-shield + "Unlocked".

## Interaction Contracts (Phase 1)

These are the locked interaction rules. Plan and executor consume directly.

1. **Reveal-secret:** click-to-toggle. Auto-hide after 30s of being shown. All reveals collapse on lock event.
2. **Per-field copy:** click `<ActionIcon>` next to field → calls Wails `CopyToClipboard({ value, secretKind, timeoutMs: 30000 })` → frontend mounts `<ClipboardCountdown>` in a fixed bottom-right card → at `n=0` calls Wails `ClearClipboard()`.
3. **Clipboard countdown progress:** decreasing fill, accent color while `n > 5`, switches to `yellow.6` while `n ≤ 5`. Updates ≥1Hz via `useInterval(() => …, 250)` (4Hz for smooth bar; PRD §9.7 minimum is 1Hz).
4. **Reset-on-new-copy:** if a new `CopyToClipboard` fires while countdown is active, the existing `useInterval` clears, the timeout resets to the new request's `timeoutMs`, and the same component re-renders. NO stacked toasts.
5. **Lock event propagation:** backend emits Wails `vault:locked` event on manual lock OR auto-lock (Phase 2). Frontend's App-root subscriber (`runtime.EventsOn`) wipes Zustand stores, collapses revealed secrets, dismisses any open `<Modal>`, calls `ClearClipboard()` for safety, and `navigate('/unlock', { state: { path: lastPath }})`.
6. **Locked-state action blocking:** when `vaultStore.status === 'locked'`, every screen except Welcome/Create/Unlock redirects to `/unlock`. The frontend api wrapper (`frontend/src/api/`) ALSO checks `status` before invoking secret-touching methods and short-circuits with a `VAULT_LOCKED` toast — defense in depth. (PRD §10 + UI-13.)
7. **Auto-focus rules:**
   - Welcome on first launch (no last-vault-path): focus `Create new vault` button. (CONTEXT D-10.)
   - Welcome on subsequent launches with a remembered path: route directly to Unlock; focus `Master password` field. (CONTEXT D-11.)
   - Create Vault: focus `Vault file location` field on mount.
   - Unlock: focus `Master password` field on mount.
   - Record Detail edit mode: focus `Title` field.
   - New/Edit Record: focus `Title` field on mount.
8. **Enter-to-submit:** Enter in any form input triggers the screen's primary CTA. Shift+Enter in `<Textarea>` (Notes) inserts newline. Standard Mantine form behavior.
9. **Escape-to-cancel:** Escape closes any `<Modal>` or `<Drawer>`. On Edit-Record, Escape triggers the discard-changes confirm.
10. **Tabs key flow:** strict logical order on every screen — Mantine's default flow honors source order; do NOT use `tabIndex` overrides except on the lock-pill (it is `tabIndex={0}` so screen readers can announce vault state).

## Accessibility Contract

- All `<ActionIcon>` (icon-only buttons) MUST have `aria-label`. Listed in copywriting tables above.
- Lock-state pill is announced by screen readers via `role="status" aria-live="polite"` so a state change ("Locked" → "Unlocked") is read.
- Color is NEVER the sole signal: lock-state has icon + text, validation errors have inline text + icon, destructive buttons have label "Delete" (not just red color).
- Contrast ratios: All body text passes WCAG AA (≥4.5:1) at both color schemes. Mantine defaults satisfy this; Phase 1 does not introduce custom text colors.
- Keyboard: every action invokable from the keyboard. No drag-only or hover-only affordances.
- Focus ring: visible on `:focus-visible`, suppressed on mouse focus. Mantine `focusRing="auto"` (default).
- `<PasswordInput>` reveal toggle inherits Mantine's built-in accessible toggle (CONTEXT specifics §3 confirms this is enabled in v0.1 by default).

## Cross-Platform Rendering Notes

- **Fonts:** System stack only. macOS resolves to SF Pro / SF Mono; Windows resolves to Segoe UI / Consolas. No webfont download — keeps Wails build deterministic and offline-capable.
- **Scrollbars:** Mantine `<ScrollArea>` for the record list and notes textarea — gives a consistent thin overlay scrollbar on macOS WebKit and Windows WebView2 (native scrollbars look very different between the two engines).
- **Focus rings:** `:focus-visible` is supported by both engines. No fallback ring needed.
- **Modal backdrop:** Mantine default `backdropFilter: blur(2px)` — confirmed working on WebView2 in `CLAUDE.md` research; macOS WebKit handles it natively.
- **Clipboard write timing:** Backend `ClipboardSetText` (Wails runtime) is synchronous; frontend can immediately mount `<ClipboardCountdown>` after `await CopyToClipboard()` resolves. CLAUDE.md §1d confirms v2.12.0 fixes a macOS Tahoe pbcopy LANG bug — keep Wails pinned to v2.12.0+.
- **Window minimum size:** `wails.json` `width: 960, height: 640, minWidth: 720, minHeight: 480`. Vault Home is the most cramped screen and needs ≥720 wide for header buttons + record list to coexist.
